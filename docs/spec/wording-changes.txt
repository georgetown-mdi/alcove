- - -> An acceptor's run states the authored server's `invitationRelay`, where it has one, as `invitation_relay`, as `alcove accept` writes it.

- - -> `invitationRelay` is the relay an accepted invitation names, which the console's accept sends with that invitation's server: a strict object naming at least one list and no other key, a credential included, each list of 1 to 8 urls (core's `MAX_RELAY_LOCATOR_URLS`), each url at most 1024 code units and held to core's `TurnUrlSchema` or `StunUrlSchema`.
- - -> A `PUT` without it leaves the server with no relay.
