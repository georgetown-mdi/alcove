# The transform regex dialect may change between releases; two signaling caps are working values.
- A change to the permitted syntax, the flag set, the Unicode mode, or the engine's match/replace/split semantics is a wire-compatibility event: it changes what a pattern means or whether it is valid, and two parties running different dialects would silently derive different keys. -> A change to the permitted syntax, the flag set, the Unicode mode, or the engine's match/replace/split semantics is a dialect change: it changes what a pattern means or whether it is valid.
- The linkage-terms [`version`](../EXCHANGE_REFERENCE.md#linkage-terms) field does not by itself prevent this -- it is an operator-authored schema version, compared only for equality between the two parties' authored values, and is not bound to the engine or dialect a party actually runs (two parties can declare the same `version` while running different Alcove releases). -> The dialect may change between releases, as a default pipeline may ([DEFAULT_STANDARDIZATION.md](DEFAULT_STANDARDIZATION.md#cross-party-invariant)).
- A dialect change therefore MUST be accompanied by a `version` bump in this specification and requires the two parties to run releases that implement the same dialect; the protocol does not currently negotiate or hash an engine/dialect version at runtime, so this is a process obligation rather than a guarantee the handshake enforces. -> Two parties whose dialects give a pattern different meanings can derive different keys, and nothing in the handshake detects it, so the release notes name each change of meaning.
- Binding the dialect to a runtime-negotiated version is tracked as follow-up work. -> A change that makes a pattern invalid is refused by name: the party whose dialect no longer accepts the pattern rejects it at terms validation, before any row is processed.
- It takes no bump, as the size cap takes none: below `1.0.0` partners upgrade together, so there are no mixed-version peers to hold apart ([Wire-format deltas: existing frames only, and no version bump](#wire-format-deltas-existing-frames-only-and-no-version-bump)). -> -
