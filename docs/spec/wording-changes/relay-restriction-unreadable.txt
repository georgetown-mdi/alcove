# as none saved, rather than refusing every browser run.
- A CLI connection's `allowed_relays` ([EXCHANGE_REFERENCE.md](../EXCHANGE_REFERENCE.md#connectionallowed_relays)), and a browser's allowed relays on its Relay server page (`runRelayRestriction` in `apps/web/src/psi/transport/relayRestriction.ts`), then leave out every TURN url no entry names, matching an entry's host without resolving it and, where the entry names a port, the url's port, 3478 for a `turn:` url naming none and 5349 for a `turns:` one (`turnUrlIsAllowed` in `packages/core/src/config/connection.ts`). -> A CLI connection's `allowed_relays` ([EXCHANGE_REFERENCE.md](../EXCHANGE_REFERENCE.md#connectionallowed_relays)), and a browser's allowed relays on its Relay server page (`readRelayRestriction` in `apps/web/src/psi/transport/relayRestriction.ts`), then leave out every TURN url no entry names, matching an entry's host without resolving it and, where the entry names a port, the url's port, 3478 for a `turn:` url naming none and 5349 for a `turns:` one (`turnUrlIsAllowed` in `packages/core/src/config/connection.ts`).
- A stored browser setting this build cannot read keeps no TURN url, and a browser run under it is refused before it contacts any host. -> A browser run treats stored allowed relays this build cannot read, and storage it cannot read at all, as none saved.
- When this browser's storage cannot be read at all, a saved relay restriction is not applied, and the run uses relays as if none were saved; a stored value that can be read but not parsed refuses every run. -> -
