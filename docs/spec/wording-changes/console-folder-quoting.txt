# The spec states what the pasted-text escaping note leaves out: the shell it
# covers, PowerShell quoting, and a comma or double quote in a --mount source.
- - -> The note on a path or name pasted between double quotes (`PASTED_TEXT_ESCAPING_NOTE`) covers a Linux or macOS shell only, and has two limits.
- - -> No note says what a path or name needs inside a PowerShell line's double quotes.
- - -> And a folder pasted into a `--mount` source still cannot hold a `,` or a `"` once it is escaped for the shell, since `--mount` reads its value as CSV, the reason `unmountableBindPaths` refuses such a path; the note does not say so.
