# close() waits for an in-flight rendezvous write before cleanup(), so an
# interrupted hello publish leaves nothing the next run refuses.
- - -> Before the drain, `close()` waits for a rendezvous write still in flight to settle, together with its `responsibleFiles` change: the hello on the hello-exchange path, the joiner's sentinel, and the joiner's step from deleting the peer hello to its own hello.
- - -> A hello that lands after a SIGINT or SIGTERM has started teardown is therefore tracked and swept, not left for the next run's entry guard to refuse as this party's own.
- - -> The abort that precedes the wait stops the rendezvous from starting another such write, so the wait covers every one that can still land.
- - -> It is bounded by `RENDEZVOUS_WRITE_SETTLE_TIMEOUT_MS` (30s) applied as `min(RENDEZVOUS_WRITE_SETTLE_TIMEOUT_MS, inactivity_timeout_ms)`, internal-only rather than a config setting.
- - -> A write that lands after the bound is left on disk.
- Above those two waits sits the run's own teardown ceiling, **3 min** on both file-based channels: the point at which a finished CLI run stops waiting for its transport to close, whatever is still running beneath. -> Above those waits sits the run's own teardown ceiling, **3 min** on both file-based channels: the point at which a finished CLI run stops waiting for its transport to close, whatever is still running beneath.
- It is above the drain (60 s) and the transport close (30 s) together, with the SFTP adapter's own client-close, forced-close and deferred-cleanup drains smaller again, so reaching it means a close overran every bound beneath it. -> It is above the rendezvous write settle (30 s), the drain (60 s), and the transport close (30 s) together, with the SFTP adapter's own client-close, forced-close and deferred-cleanup drains smaller again, so reaching it means a close overran every bound beneath it.
- - -> A `close()` that runs while a rendezvous write is in flight waits for that write and its `add` before `cleanup()` ([Phase 3](#phase-3----cleanup-and-close)), so teardown does not open the window either.
