# A browser run lists an invitation's STUN urls in place of the default STUN
# server, as a CLI run does.
- It lists the default STUN server first unless the browser's relay setting names STUN urls of its own, which then take its place (`buildIceServers` in `apps/web/src/psi/transport/rendezvous.ts`); STUN urls only the invitation names are listed after the browser's own or the default STUN server, not in its place. -> It lists the default STUN server only where neither the browser's relay setting nor the invitation names a STUN url; otherwise its STUN urls, the setting's and the invitation's, take the default's place, as a CLI run's do (`buildIceServers` in `apps/web/src/psi/transport/rendezvous.ts`).
- - -> An acceptor's network address so goes to the STUN servers the invitation names in place of the default, and an acceptor that reaches none of the STUN servers it lists gathers no server-reflexive candidate, which the default might have given it.
- Its ICE servers hold the default STUN server unless the browser's relay setting names STUN urls of its own ([Which relay a run uses](#the-invitations-relay-locator)). -> Its ICE servers hold the default STUN server only where neither the browser's relay setting nor the invitation names a STUN url, and those STUN urls in its place otherwise ([Which relay a run uses](#the-invitations-relay-locator)); the default relay adds no STUN url.
- A STUN list saved in relay settings before the setting replaced the default replaces it from this version on; the web app shows no notice of the change. -> A STUN list saved in relay settings before the setting replaced the default replaces it from this version on, and STUN urls in the invitation relay of a saved exchange replace it from this version on too; the web app shows no notice of either change.
- - -> An acceptor that cannot reach the STUN servers its invitation names gathers a server-reflexive candidate again once its own relay settings list a STUN url it can reach, Google's included, since its own and the invitation's urls are listed together.
