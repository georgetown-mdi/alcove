- - -> One that kept the next secret, such as the CLI or a saved browser exchange, adds that this side holds it; the one-off browser exchange, which keeps no secret past a failed run, says that nothing changed on this side.
- - -> Any other reason, or this one on a side that stored nothing, reads as any partner abort.
