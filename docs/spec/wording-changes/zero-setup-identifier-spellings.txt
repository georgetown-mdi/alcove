- - -> So does a record number: a name whose lookup key ends in `_number`, `_no`, or `number` after at least one other character, such as `case_number`, `Record No`, or `CaseNumber`, or whose header ends in a lowercase letter followed by `No`, such as `RecordNo`.
- - -> A header ending in a lowercase `no`, such as `Casino`, is not a record number.
- - -> Nor is a name whose lookup key, before the suffix and with `_` removed, ends in a table name of any type but `identifier`, in the part of such a name before its own suffix (`phone` of `phone_number`, `socialsecurity` of `social_security_number`), or in `mobile`, `cell`, `fax`, `tel`, or `yes`: `phone_no`, `Home Phone Number`, `SocialSecurityNumber`, and `yes_no` infer as any other name absent from the table.
