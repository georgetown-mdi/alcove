# The update-route table in DEPENDENCY_PINS.md, all added.
- - -> Every pin's update route
- - -> Every image, package, vendored module and exact tool version the repository pins, as surveyed on 2026-11-10, with the route that offers it for upgrade:
- - -> **automatic**: a block in `.github/dependabot.yml` reaches the pin and opens a pull request.
- - -> **scheduled**: a documented manual cadence moves the pin.
- - -> No pin has one.
- - -> **planned**: a scheduled cadence for the pin is planned and not yet documented.
- - -> **none**: nothing offers an upgrade, and the pin moves only when someone edits it.
- - -> A route says how an upgrade is offered, not how it is reviewed.
- - -> The reviewed groups, the literals that move in the same diff and the checklists are in the section each row links.
- - -> Pin | Where | Recorded as | Route | How it moves
- - -> `@openmined/psi.js` | `lib/openmined-psi.js-2.0.6-seclink.6.tgz`, a `file:` dependency of `packages/core`, `apps/cli` and `apps/web` | Version in the file name, the sha256 sidecar, and the lockfile `integrity` | none | The `npm` block at `/` ignores every version update of it. A rebuild follows [PREBUILD_REVENDOR.md](../PREBUILD_REVENDOR.md), and [The vendored @openmined/psi.js addon](#the-vendored-openminedpsijs-addon) states what it must keep.
