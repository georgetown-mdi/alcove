- - -> The internal assumptions
- - -> **Deep imports.**

- - -> So the client imports the modules it uses by path, all through `browserSsh/sshLibrary.ts`.

- - -> That file enters `algorithms/sshAlgorithms` first: `algorithms/publicKeyAlgorithm`, `io/sshData` and `algorithms/sshAlgorithms` require one another in a cycle, which completes only in that order.
- - -> **The `diffie-hellman` load and call split.**
- - -> `algorithms/web/webKeyExchange.js` requires `diffie-hellman` when it loads, and calls it only for a negotiated finite-field key exchange.
- - -> The client offers ECDH alone (`ecdh-sha2-nistp256`, `-384`, `-521`), so every browser config aliases the package to a stub that throws `BrowserSshUnsupportedKeyExchangeError` (`browserSshDependencyAliases`, `apps/web/vite.config.ts`).
- - -> The client build guard fails a browser bundle holding any package of the chain (`apps/web/hosted/moduleGraphGuard.ts`).
- - -> **`node-rsa`.**
- - -> `algorithms/node/nodeRsa.js` requires `node-rsa` inside a function, and the package does not declare it.
- - -> A bundler still resolves it, so it is aliased to a stub as well.
- - -> **The `self` switch.**
- - -> `algorithms/sshAlgorithms.js` picks its WebCrypto classes when `self` is an object and `crypto.subtle` exists, and otherwise requires its `algorithms/node/` classes.
- - -> A production build bundles those Node modules but never loads them in a page.
- - -> **The negotiation message.**
- - -> A failed negotiation rejects `connect()` with a plain `Error` reading `Failed <category> negotiation: Server (<list>) Client (<list>)` (`services/keyExchangeService.js`).
- - -> `browserSshErrors.ts` reads it into `BrowserSshNoCommonAlgorithmError`.
- - -> A reworded message reaches the caller as the library's own error, unnamed.
- - -> **`vscode-jsonrpc`.**
- - -> The library uses only its `Emitter`, `Event`, `Disposable`, `CancellationToken` and `CancellationTokenSource`.
- - -> The package's main entry reads a `Buffer` global when it loads, and requires `net`, `os` and `crypto`.
- - -> So the browser configs alias the bare specifier to a module re-exporting the package's own `lib/events` and `lib/cancellation` (`browserSsh/stubs/vscodeJsonrpc.ts`).
