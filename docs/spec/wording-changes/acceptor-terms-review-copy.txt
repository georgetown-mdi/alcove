- - -> A party set to receive no output is the sender ([Role resolution and work minimization](#role-resolution-and-work-minimization)), is sent none of the other party's payload columns, and saves no result, so the command-line prompt marks its No as enforced, and the web app's terms review and settled footer state it with no qualifier.

- - -> In the cascade, and in single-pass when the partner sends columns, matching also sends the partner the other party's row number for each of its matched records, which it does not save; the web app's send row counts these as matching and reads "Nothing - matching only".
