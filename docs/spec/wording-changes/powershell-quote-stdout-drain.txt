- - -> The one-off Windows command is a PowerShell command (`powerShellJoinCommand`), where the Task Scheduler line's action is quoted for `cmd.exe`.
- - -> A token is left bare only when it starts with a letter, `_`, `/` or `./` and holds only letters, digits, `_`, `.`, `/`, `:`, `=`, `@` and `-`, or is an option of only letters, digits and hyphens after its dashes.
- - -> Every other token, and every token holding a placeholder, is a PowerShell double-quoted string with a backtick before each `$`, backtick and typographic double quote and each `"` doubled, so a `;`, `$` or backtick in it reaches `docker` as text.
- - -> The Windows CI suite (`DockerLines.Tests.ps1`) runs generated lines holding each of those under Windows PowerShell 5.1 against a `docker` stand-in.
