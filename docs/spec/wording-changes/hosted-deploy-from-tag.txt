# The hosted app deploys from the release tag and bakes in that tag's version.
- - -> A hosted build from a release tag bakes in that tag's version, and the release deploys it only after the publish job has finished ([RELEASES.md](../RELEASES.md#8-build-and-publish-the-container-image-ci)).
- Anything else, including an absent value, names the floating `latest` tag a release publishes alongside `X.Y.Z` and links the releases index, so a build that passes no version -- the continuously deployed hosted deployment, or any web build outside the image build -- prints a working command rather than an empty, partial, or placeholder tag. -> Anything else, including an absent value, names the floating `latest` tag a release publishes alongside `X.Y.Z` and links the releases index, so a build that passes no version -- a hosted build not made from a release tag, or any other web build outside the image build -- prints a working command rather than an empty, partial, or placeholder tag.
- `VITE_ALCOVE_VERSION` | The release version baked into the client bundle, and no part of the feature gate: it configures nothing server-side and every job route ignores it. The image build sets it for the web build alone from `apps/cli/package.json` (see [The partner accept kit](#the-partner-accept-kit)), which is the only consumer, and fails rather than setting it empty; unset or in any shape but a release version, the kit names the floating image tag. Set at build time, never derived from a request. -> `VITE_ALCOVE_VERSION` | The release version baked into the client bundle, and no part of the feature gate: it configures nothing server-side and every job route ignores it. The image build sets it for the web build alone from `apps/cli/package.json` (see [The partner accept kit](#the-partner-accept-kit)), and fails rather than setting it empty; the hosted build sets it from the release tag it is built from, and empty from anything else. The accept kit and the page footer read it; unset or in any shape but a release version, the kit names the floating image tag. Set at build time, never derived from a request.
