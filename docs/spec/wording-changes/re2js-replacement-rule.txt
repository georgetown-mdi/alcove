- - -> A `$<` begins a name that runs to the first `>` or space, or to the end of the replacement; the sequence is a group reference only when a `>` ends the name and the pattern has a group of that name, and otherwise it is emitted literally up to that `>` or space, so `$<x$1>` is wholly literal while in `$<x $1` the `$1` after the space is a reference.
- - -> The reference engine's update from `re2js` 2.8.8 to 2.9.1 is such a change for one shape only: a class that can never match, such as `[^\d\D]` or `\P{Any}`, inside a group or a repetition, where 2.8.8 fails with an internal error on some inputs and can report a different `programSize()`, and so a different weighted size.
- - -> It takes no bump, as the size cap takes none: pre-publication there are no deployed peers to hold apart ([Wire-format deltas: existing frames only, and no version bump](#wire-format-deltas-existing-frames-only-and-no-version-bump)).
