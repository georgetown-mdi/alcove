# Metadata inferred under count-only terms sends no identifier column.
- - -> Under count-only (`psi-c`) terms, which send no column, the inferred metadata instead sets every `identifier`-typed column not sent: the record identifier keeps `role: identifier` with `is_payload: false`, and every later one is `role: ignored`, `is_payload: false` (`withIdentifiersNotSent`, `packages/core/src/config/metadata.ts`).
- - -> An authored `metadata` block is read as written, and one that sends a column under count-only is refused ([PROTOCOL.md](PROTOCOL.md#refusals-under-count-only)).
