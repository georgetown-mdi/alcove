- - -> **The exchange id.**
- - -> A party that enrolls the relay key at a registrar without a token ([Enrolling at a default relay](#enrolling-at-a-default-relay)) enrolls it under an exchange id derived from the same secret:
- - -> exchange_id = hex(HKDF-SHA-256(ikm = secret, salt = 0x00 * 32, info = "alcove-relay-exchange-id-v2", 16))
- - -> **Its form.**
- - -> 32 lowercase hex characters, within the registrar's id alphabet.
- - -> **Why derived.**
- - -> Both parties compute it without exchanging anything, and a third party without the secret cannot predict it, so it cannot enroll the id under another key first.
- - -> **What it reveals.**
- - -> Nothing about the secret or the relay key: the info string is a single fixed label in the [domain-separation label space](#p-256-authenticated-key-exchange).
- - -> It changes at each rotation, as the relay key does.
- - -> **Test vector.**
