- - -> **On single-pass over file-sync the element length bounds the decode.**
- - -> There the ceiling is the authenticated bound alone, without `MAX_PSI_DECODE_ELEMENTS`, and the scan refuses any element that is not 33 bytes long (`PSI_ELEMENT_BYTES`; the `element-length` decode bound in `participant.ts`).
- - -> Every element of a conforming setup, request or response is 33 bytes, a compressed curve point, on both backends (`packages/core/test/psi/psiDecodeBound.test.ts`).
- - -> So no honest frame is refused.
- - -> Each element then takes at least 35 bytes of the frame, so the frame's size bounds what its decode holds, at the rate of an honest frame.
- - -> At `MAX_FRAME_SIZE_BYTES` that is about 4.1 GB, the same as an honest frame of that size.
- - -> Under the set maximum alone, 2^24 empty elements take 3.3 GiB from a 33.5 MB frame.
