- - -> The kept codes and the folds are the generational entries of the suffix list in [Affix removal](#affix-removal), so a party's suffix column and its stripped name column agree.
- - -> A value that is none of the five codes after folding is dropped.
- - -> This drops the professional suffixes of that list, such as `Esq`, `MD` and `PhD`, and the single-letter numerals `I` and `V`, which the name cleaning leaves on the name; a dropped value cannot make a false match.
- - -> It also drops a filler such as `N/A` or `None`, a digit the list does not hold, such as `3`, and a value of more than one word.
- - -> A value holding several suffixes, such as `Jr MD`, is dropped whole, as is `Smith Jr`: the cleaning does not pick one word out of several.
- - -> Uppercasing maps a dotless i and a long s to `I` and `S`, so `ıı` cleans to `II`; any other letter outside ASCII is not folded, so a fullwidth letter or a Roman-numeral character is dropped.
- - -> The empty suffix is a value, not a missing one:
- - -> A blank cell, a cell of whitespace, and a cell of ASCII punctuation alone, such as `-`, clean to `""`: once punctuation is removed, such a cell is the same as a blank, so two parties cannot clean it differently.
- - -> A cell of non-ASCII punctuation alone, such as an en dash or a curly quote, is dropped.
- - -> Every other pipeline in this document drops such a cell; this one keeps it, so a record with no suffix matches a record with no suffix on a key holding the suffix element.
- - -> An empty suffix matches only an empty suffix.
- - -> `JR` does not match `""`, so such a key tells a parent from a child of the same name where both files record the suffix, and misses the pair where only one file does.
- - -> A row too short to hold the column has no value for it, and is left out of every key holding the suffix element, as for any field.
- - -> The other elements of a key keep their own rules, so a record whose name is blank builds no key, whatever its suffix.
- - -> The type is read from a column of its own, inferred from the names `suffix`, `name_suffix` and `namesuffix` ([Type inference from column names](#type-inference-from-column-names)).
- - -> The defaults do not derive it from a name column: the `first_name` and `last_name` pipelines remove a trailing suffix ([Affix removal](#affix-removal)) and keep nothing of it.
- - -> A column named `suffix` is read as a name suffix, so a street-suffix column with that name has every value dropped as not a name suffix and is not sent as payload; name it `street_suffix` to keep it as payload.
