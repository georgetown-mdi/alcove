# The macOS prebuilds' minimum macOS version, per architecture.
- Both macOS prebuilds are built for macOS 15.5 or later, so a Mac at that version loads the native addon and an older one falls back to WASM. -> The darwin-arm64 prebuild is built for macOS 11.0 or later and the darwin-x64 prebuild for macOS 10.15 or later, a floor the fork's prebuild workflow checks; an older Mac falls back to WASM.
