- The limit is that a one-letter first name also takes part in the keys on the whole first name and a date of birth, such as `LN + FN + DOB`, where an initial written in place of a name agrees with any record holding the same initial, surname and date. -> Every built-in key on the whole first name, such as `LN + FN + DOB`, drops a one-letter first name with a `filter_regex` step on its own first-name element, so a record holding only an initial matches through keys on part of the first name, such as `SSN + LN + FN1`, and not through these.
