- A received payload is not compared against `payload.receive` again after it crosses. -> After the payload exchange, a party that receives payload compares the received column names against the partner's agreed `payload.send` (`assertPayloadMatchesAgreedSend`), and the run ends with a `protocol` error, before its result is returned, when they differ.
- The one check after the payload exchange is for a party that receives no payload at all ([The no-output send gate](#the-no-output-send-gate)). -> A party that receives no payload at all refuses any column sent to it instead ([The no-output send gate](#the-no-output-send-gate)).
