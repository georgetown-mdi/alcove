- The receiver holds a response to at most the length of the request it sent, not to that length, and matches a shorter one as it stands. -> The receiver refuses a response whose element count is not the element count of the request it sent, in one frame and in parts, as a `protocol` error before it matches any of it, so it sends no resolved table.
