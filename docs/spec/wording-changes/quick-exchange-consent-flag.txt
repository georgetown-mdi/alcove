# The payloadReceiveTaken row says the same.
- `payloadReceiveTaken` | An unattended run -- no terminal on stdin -- took the payload columns its partner declares it sends, because its terms list none it receives (`linkage_terms.payload.receive`), and asked no question. The message states the notice the run writes on `stderr` at every log level, naming each column and the configuration they were written to, or that they were written to none, with the configuration path escaped for display where `stderr` shows it as the operator typed it. Raised once, at the terms exchange before any linkage key or data moves; a zero-setup `--save` run raises it once its save outcome is known, before the terminal event. The event also holds `columns` and `columnCount` ([Payload columns taken without asking](#payload-columns-taken-without-asking)). -> `payloadReceiveTaken` | A run took the payload columns its partner declares it sends, because its terms list none it receives (`linkage_terms.payload.receive`), and asked no question.
