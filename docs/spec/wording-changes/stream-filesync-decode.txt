- - -> A single-pass party therefore moves the partner's frame to the PSI worker rather than copying it (`PsiFrameHandOff`, `packages/core/src/psi/psiEngine.ts`):
- - -> **The request.**

- - -> **The reply.**

- - -> The engine checks each piece as it checks a setup received in parts, and frees the pieces it took on a refusal.
- - -> The response then moves with the reply's buffer, once it is held to the request this party sent.
